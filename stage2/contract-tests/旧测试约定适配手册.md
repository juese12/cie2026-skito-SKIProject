# 旧测试的 e8/e16 合同适配

本目录的功能和完整控制适配均已通过现有新核差分、GOOD TRAP 和退出 0，详见[修复报告](../reports/旧测试元素宽度约定修复记录.md)。本目录复用旧源码，以显式合同编译新镜像，原已验收镜像不覆盖。

## 合同选择

`stage2/test-contract.h` 为 C 和汇编提供同一选择。共享旧源码的默认 `VDOT_TEST_E16=0` 保持 e8-only 历史合同；本目录适配器定义为 1，选择当前 e8/e16 合同。当前 `stage2/sew16/` 适配器也显式选择 1，替代原先将所有 `e16` token 替换为 `e32` 的处理。

| 项目 | 历史 e8-only（0） | 当前 e8/e16（1） |
| --- | --- | --- |
| 功能套件 SEW 非法例 | e16 | e32 |
| 控制套件最终非法配置 | VL7 / e16 | VL7 / e32 / e64 |
| 最终 SEW 请求 AVL | 8 | 8 |
| 最终 SEW 配置实际 VL | e16：8 | e32：4、e64：2 |
| vtype 的 SEW 编码部分 | 8 | 16、24 |
| 功能套件 e16 合法例 | 不执行 | 32 个正负/极值/零/四策略例，完整 128 位与 CSR 检查 |

`vsetvl` 会把 AVL 限制到 VLMAX。e32/e64 的异常既要检查指令位 tval，也要准确检查 trap 恢复前的 VL/vtype，不能仍期望 VL=8。

NEMU API 测试也要求显式 `--contract`，不从参考库文件名猜测能力：

```bash
python3 stage2/tests/check-nemu-vdot.py ../NEMU/build/riscv64-nemu-interpreter-so --contract e8-only
python3 stage2/tests/check-nemu-vdot.py ../NEMU/build/sew16/riscv64-nemu-interpreter-so --contract e8-e16
```

历史合同实际通过 1035 合法/10 非法；当前合同实际通过 1403 合法/11 非法，包含 368 个 e16 合法例、e32/e64 非法和非 vdot custom-0 的 tval 隔离。

## 构建、运行和复核

从作品根目录执行：

```bash
source ../env.sh
make -C stage2/contract-tests ARCH=riscv64-xs KIND=functional
make -C stage2/contract-tests ARCH=riscv64-xs KIND=control
python3 stage2/contract-tests/test_contract_selection.py -v
bash scripts/run-vdot-contract-tests.sh --check
bash scripts/run-vdot-contract-tests.sh
```

功能适配默认 RANDOM_CASES=0，覆盖原 52 合法检查、10 非法检查和新增 32 个 e16 合法检查；可用 `RANDOM_CASES=1000` 构建独立完整功能镜像，但默认 runner 只选择 r0。控制适配保留原 256 随机、64 次训练、4 次探测、20 次异常、24 个配置组、16 个最终非法组、16×32 混发和 16×128 依赖链。数据/初始化种子为 56444f54/101；不称为新核四独立进程验收。

runner 固定使用 `XiangShan/build/sew16-fixed8/emu` 和 `NEMU/build/sew16/riscv64-nemu-interpreter-so`，串行运行两个新镜像，不生成波形。控制日志复用 `check-vdot-control.py` 的架构审核，内部推测控制状态仍为 NOT_AUDITED。长时间任务每 40 分钟检查一次。

最终镜像现在与对象文件一起放在 `build/contract-v2-功能类型-r0-seed0x56444f54/`，其中功能类型为 `functional` 或 `control`。Makefile 显式设置 `BINARY`，runner 使用 `make --no-print-directory -s KIND=功能类型 print-image` 查询同一路径。此前 `DST_DIR` 只约束对象目录，最终镜像仍在平铺目录；不能单凭 `DST_DIR` 推断二者不匹配。旧平铺镜像保留，runner 不再回退使用它。

路径调整时先编译两份镜像，功能镜像 9752 字节、控制镜像 11160 字节，分别与历史成功镜像逐字节一致，预检通过。随后已在独立目录用新编译 emu/ref 实际执行两套镜像，功能为 27074 指令/79758 核周期，控制为 368214 指令/232893 核周期，差分、GOOD TRAP 和退出均通过；与历史两套合同的指令数/周期一致。原成功日志仍保留其原运行范围。实测见[独立复现报告](../reports/公开包独立目录复现报告.md)，入口见[交付复现手册](../../docs/公开交付与干净复现操作手册.md)。

原源文件快照在 `before/`。预处理/编译检查包括实际宏选择、旧合同 `.text` 字节等价和非法选择拒绝；它们验证测试适配，不能替代整核差分。本轮首次构建因 C/汇编同名导致对象冲突，已把 C 适配器命名为 `*-main.c`，失败日志保留。实际运行完成情况见[修复报告](../reports/旧测试元素宽度约定修复记录.md)。
