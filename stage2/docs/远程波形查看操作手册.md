# Surver 本机远程波形操作手册

查看器通过 `start --wave` 显式选择本地波形。公开材料中的 P1 关键信号可直接在[优化对照报告](../../stage3/reports/原始核至P1优化对比报告.md)及其采样 JSON 中查看。

配置并验证。目的：绕过VS Code资源代理下载整份多GiB VCD的链路，由WSL服务端解析，浏览器只请求层级、时间表和选中信号。原始VCD不转换、不覆盖、不删除。

## 配置与实际验收（历史，不是实时状态）

- 官方预编译Surver `0.7.0 (git: c9db19e)`；Wellen协议版本`0.25.6`。
- 用户级瞬态服务`vdot-surver.service`，WSL尚在运行时独立于终端会话。**不是开机自启动服务**；关闭WSL/重启后须重新start。
- 浏览器入口`127.0.0.1:8911`，Surver后端`127.0.0.1:8912`；两个端口都仅绑定回环地址。8912为内部接口，连接时使用8911。
- 每次start生成随机令牌，连接URL在`private/surver/run/connection.txt`，权限600，所在run目录权限700；整个private目录被Git忽略。URL相当于密码，不能贴到公开报告/截图。后台日志也可能含令牌，只留在private。
- 轻量本机代理补齐浏览器CORS响应，并保留`Server: Surfer`、`x-wellen-version`等协议识别头。固定转发到本机8912，不是通用网络代理；只有正确令牌路径可访问数据，错误令牌返回404。
- 同时只加载一份波形，Rayon工作线程2；MemoryHigh=2GiB、MemoryMax=4GiB、MemorySwapMax=2GiB，失败不自动循环重启。浏览器客户端本身的内存不计入此服务上限。
- 当时加载波形原版本波形文件，5238847771字节（约4.88GiB）。服务端波形体解析21.8秒，观测服务MemoryPeak约2.0GiB；本次未探测当前服务。
- 小波形`VDot8-final.vcd`协议检查通过；P1大波形完整解析后，层级/时间表/一个信号请求、CORS及无效令牌拒绝通过；Windows PowerShell实测访问本机入口HTTP200。大波形压缩层级响应13571834字节，时间表83字节、单个测试信号7字节；这些不是完整用户浏览会话的总流量。
- 已验证服务端及Windows连通；客户端Wellen协议版本必须兼容，若界面报告版本不匹配，应更新Surfer扩展后再试，不修改原波形。

## 在 VS Code 中连接

在WSL终端进入作品根目录：

```bash
cd /home/saintrikashy/riscv/xs-env/cie2026-skito-SKIProject
python3 scripts/surver-remote.py url
```

复制输出的完整`http://127.0.0.1:8911/随机令牌`（不要漏掉令牌）。在Surfer波形面板内部选择 **File → Open URL**，粘贴URL。若还没打开Surfer面板，可以先打开小文件`stage2/waveform/isolation/VDot8-final.vcd`，再用其内部File菜单切换到URL。

不要双击4.88GiB的原VCD来连接，那会继续走VS Code资源代理；不要将URL粘贴到“打开本地文件”对话框。浏览器地址栏访问URL只显示服务状态页，不是波形查看器。

层级加载后只添加需要的clock/valid/ROB/vdot等信号，不一次性添加整个整核层级。远程模式避免整份文件下载，但不保证无限信号数量下的浏览器内存占用。

Windows→WSL localhost访问已实测成功。若重启后不可达，可在VS Code **Ports/端口**面板转发WSL的8911端口，保持本机/私有可见；若本机转发端口不同，替换URL中的端口但保留完整令牌。无需向局域网绑定`0.0.0.0`或开公网端口。

## 启停、切换及检查

以下命令从作品根目录、正常WSL终端运行；受限终端中操作用户服务管理器需要提升执行权限。

已完成结果及当前复核方式见[版本与复核入口](../../docs/核与参考库版本选择.md)。

服务启动不等于波形体已解析完。`status`中的`last_modification_time`非null且未reloading，表示本版服务端完成波形体解析；进度字节数来自缓冲读取估算，可能稍大于预计长度，不能要求相等。`check`还会实际请求层级/时间表/一个信号，不只是确认端口存在。

```bash
systemctl --user show vdot-surver.service \
  -p ActiveState -p SubState -p MemoryCurrent -p MemoryPeak
```

若启动后立刻访问出现连接失败，先等头部解析、再status。若达到内存上限退出，不取消保护门槛盲目重试：先减少同时加载量或另行生成FST查看副本，并重新评估内存。服务不是HTTPS，仅适用于当前回环/本机转发；其他机器访问必须配置安全隧道，不能直接开放端口。
