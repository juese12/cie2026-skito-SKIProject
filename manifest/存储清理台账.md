### 清理后的复查与真正重采

从作品目录执行默认只读检查：

```bash
python3 scripts/replay-isolation-evidence.py
```

该入口不启动 CPU，原始 VCD 不存在时仍能核对复现输入及保留数据。真正重采必须显式选择实验、使用不存在的新输出目录：

```bash
python3 scripts/replay-isolation-evidence.py --run control \
  --out-dir stage2/logs/isolation-control-replay-NEW
python3 scripts/replay-isolation-evidence.py --run e2e \
  --out-dir stage3/logs/isolation-fast-slow-replay-NEW
python3 scripts/replay-isolation-evidence.py --run middle \
  --out-dir stage3/logs/isolation-middle-replay-NEW
```

这三条会重新跑旧隔离核，可能耗时数小时，并输出新日志/VCD/审核。本轮没有执行它们，也没有启动最新核。保证保留了当前本地环境下复现实验所需的固定输入与检查程序；未重采不能写成“重新通过”。当前入口不调用会因源码升级/旧采集文件缺失而失效的恢复编排器，不重建最新源码，也不以最新核代替旧核。

精简是不可直接撤销的原始数据删除：可复查已保存的控制窄窗和 693 个周期信号，不能查看未保存的其他内部信号。重新采集不承诺 VCD 字节相同，迁移目录、替换核/库或改变工具环境需要重新确认条件。
