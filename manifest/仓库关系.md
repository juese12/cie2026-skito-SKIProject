# 仓库关系

| 名称 | 用途 | 本地位置 |
| --- | --- | --- |
| `xs-env` | 比赛开发环境入口 | 作品仓库的父目录 |
| `XiangShan` | RTL 生成及 Verilator 仿真 | `../XiangShan` |
| `NEMU` | 参考模型及差分测试 | `../NEMU` |
| `nexus-am` | 裸机程序和运行时 | `../nexus-am` |
| `DRAMsim3` | COSIM 主存时序模型 | `../DRAMsim3` |
| `NutShell` | 环境自检用例 | `../NutShell` |
| `XiangShanLab` | 官方加密提交材料与 PR 流程，不是作品源码仓库 | `../XiangShanLab` |

目标 GitHub 公有仓库：`https://github.com/juese12/cie2026-skito-SKIProject`

依赖的精确提交号见 `submodule-commits.txt`。本仓库只保存参赛代码、补丁、脚本和文本证据，不复制大型构建产物。

当前发布复现使用 `release-dependencies.json` 指定 24 个依赖仓库，包含 NEMU 构建时隐式获取的五项；`release-toolchain.json` 记录本轮工具版本。源码包含评审图件和选定原始数据，大型历史二进制与完整波形保留开发归档。[文档阅读指南](../docs/提交文档阅读指南.md)列出阶段材料，[独立目录实测](../stage2/reports/公开包独立目录复现报告.md)提供构建与回归结果。
