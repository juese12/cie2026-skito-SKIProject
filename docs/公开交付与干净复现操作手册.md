# 工程构建与复现手册

本手册重建当前固定八项 e8/e16 设计。依赖版本见 `manifest/release-dependencies.json`，工具版本见 `manifest/release-toolchain.json`，补丁应用方式见[补丁说明](../stage2/patches/vdot补丁选择与应用说明.md)。同主机独立目录的实际结果见[复现报告](../stage2/reports/公开包独立目录复现报告.md)。

## 1. 准备工作区

需要 Git、Make、C/C++、Python、Flex/Bison、Java、Mill、Verilator、RISC-V 交叉工具链、firtool，以及 zlib/zstd、SQLite 等开发库。实际验证使用 Mill 0.12.3、Java 21、Verilator 5.048、GCC/RISC-V GCC 15.2 和 firtool 1.62.1。

从解压后的作品根目录执行，将工作区变量替换为尚不存在的绝对路径：

```bash
REPRO_WORKSPACE="/请替换为新目录的绝对路径/sew16-repro"
python3 scripts/prepare-clean-workspace.py --destination "$REPRO_WORKSPACE"
cd "$REPRO_WORKSPACE/cie2026-skito-SKIProject"
source ../env.sh
```

准备脚本检出清单中的 24 项依赖，复制作品源码，生成环境文件，应用 XiangShan、NEMU 和 Difftest 三份当前补丁；使用此入口后无需重复手动应用补丁。已有本地依赖时可附加 `--source-workspace 本地依赖目录绝对路径`，仅复用 Git 对象。工具不在 PATH 时，分别用 `VDOT_CMAKE`、`VDOT_FIRTOOL` 指定其可执行文件。

## 2. 构建参考库、软件和整核

```bash
make -C ../NEMU vdot-v0.1_defconfig 'git_commit='
make -C ../NEMU -j2 BUILD_DIR="$NEMU_HOME/build/sew16" 'git_commit='
python3 stage2/sew16/check-reference.py ../NEMU/build/sew16/riscv64-nemu-interpreter-so
bash scripts/prepare-vdot-dramsim.sh
make -C stage1/hello-xiangshan ARCH=riscv64-xs
make -C stage1/vector-add ARCH=riscv64-xs
make -C stage2/contract-tests ARCH=riscv64-xs KIND=functional
make -C stage2/contract-tests ARCH=riscv64-xs KIND=control
make -C stage2/sew16 ARCH=riscv64-xs
make -C stage3/sew16-perf ARCH=riscv64-xs
bash scripts/build-vdot-sew16-core.sh --check
bash scripts/vdot-step.sh repro-core-build bash scripts/build-vdot-sew16-core.sh
```

`--check` 只做预检。整核生成经过 CHIRRTL、firtool、Verilator/C++，输出到 `XiangShan/build/sew16-fixed8/`。NEMU 输出到 `NEMU/build/sew16/`。构建目录已有产物时脚本拒绝覆盖。

## 3. 功能与整核差分

以下命令从新工作区的作品根目录执行，记录使用新路径：

```bash
REPRO_RECORD_DIR="$(mktemp -d "$PWD/stage2/logs/repro.XXXXXX")"
REPRO_EMU="$NOOP_HOME/build/sew16-fixed8/emu"
REPRO_REF="$NEMU_HOME/build/sew16/riscv64-nemu-interpreter-so"
bash scripts/vdot-step.sh repro-hello "$REPRO_EMU" --diff="$REPRO_REF" -i "$PWD/stage1/hello-xiangshan/build/cie2026-stage1-hello-riscv64-xs.bin" --max-cycles=300000 --seed=101
bash scripts/vdot-step.sh repro-vadd "$REPRO_EMU" --diff="$REPRO_REF" -i "$PWD/stage1/vector-add/build/cie2026-stage1-vector-add-riscv64-xs.bin" --max-cycles=300000 --seed=101
bash scripts/run-vdot-contract-tests.sh --check
bash scripts/run-vdot-contract-tests.sh
set -o pipefail
bash scripts/vdot-step.sh repro-sew16 bash scripts/run-vdot-sew16.sh | tee "$REPRO_RECORD_DIR/sew16-coordinator.log"
REPRO_FULL_LOG="$(sed -n 's/^\[sew16 regression COMPLETE\] //p' "$REPRO_RECORD_DIR/sew16-coordinator.log")"
python3 stage2/sew16/check-core.py "$REPRO_FULL_LOG" --coordinator "$REPRO_RECORD_DIR/sew16-coordinator.log" --out "$REPRO_RECORD_DIR/sew16-audit.json"
```

| 检查 | 预期 |
| --- | --- |
| Hello / 标准向量加法 | 团队输出 / 37 元素结果正确，差分、GOOD TRAP、退出 0 |
| 参考模型 | 2304 合法、96 非法及四数据种子通过 |
| 合同功能 | 52 既有合法、10 非法及 32 e16 合法检查通过 |
| 合同控制 | 分支、异常、配置切换、混发、v0 和长链通过 |
| 完整扩展 | 1564 e8、836 独立 e16，加共享套件 32 e16 正例通过 |

内部 ROB 同代次取消验证使用[专用短实验](../stage2/e16-events/e16短控制实验操作手册.md)，与上述架构状态回归分别统计。

## 4. 性能与应用

当前微基准的计时、配对与运行命令见[v4 测量手册](../stage3/sew16-perf/性能测量与复核手册v4.md)。INT8 GEMV 的构建、独立参考、差分和四进程采样见[应用说明](../stage3/int8-gemv/INT8矩阵向量乘应用说明.md)。

已有正式数据可以在不构建仿真器的情况下复算：

```bash
python3 scripts/review-submission.py --suite performance-data --out /tmp/public-performance-review.json
python3 scripts/check-public-release.py --out /tmp/public-release-check.json
```

数据复算从原始日志重新核对结果、采样顺序、统计和 1920 行 CSV；文件清单检查同时检查公开范围、大小及全部本地文档链接。两者不启动仿真，也不核验包外历史二进制。公开文件以 `manifest/public-release-files.json` 为准。
