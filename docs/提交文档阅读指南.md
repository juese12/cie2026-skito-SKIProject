# 提交文档阅读指南

录像、三阶段文档压缩包和验证证明材料统一见[材料下载页](../提交材料/README.md)。

本作品基于香山昆明湖 V2，实现固定八项有符号 `vdot.vv`。当前硬件版本为 `sew16-fixed8`，VLEN=128、LMUL=1、VL=8，支持 e8/e16；e8 为赛题基础实现，e16 为扩展。指令微基准采用 v4 协议，INT8 GEMV 为独立应用验证。
