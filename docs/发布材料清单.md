# 发布材料清单

发布范围为固定八项 e8/e16 的源码、操作脚本、评审文档与图件，以及当前 v4 性能数据的离线复算材料。当前提交材料包含小型 INT8 GEMV 应用源码、正式数据、三张信号图及补拍讲稿。依赖仓库由独立清单指定，构建目录不进入源码包。独立目录复现采用同一主机上的工具链，从新检出的源代码重新编译，不等同于全新操作系统验收。

本轮独立目录的真实构建与全部计划回归已通过，结果、命令和两张新模块波形见[复现报告](../stage2/reports/公开包独立目录复现报告.md)。源码发布目录为 `releases/sew16-public/cie2026-skito-SKIProject/`，位于开发环境根目录下；源码包与本轮模块波形证据包分别生成。

实际构建使用的是收尾前的 v2 候选树。最终包补入文档、图件和日志后，做了解压、清单、链接及数据复算；没有从最终压缩包再启动一次完整整核构建。41 份程序编译输入和 20 个补丁文件与实跑树一致，具体核对记录见复现报告。

## 源码与复现入口

- `manifest/release-dependencies.json`：24 个主仓库、子仓库及 NEMU 构建时隐式仓库的依赖版本和来源。
- `scripts/export-public-release.py`：筛选源码、文档、图件和可复算数据，输出逐文件清单。
- `scripts/check-public-release.py`：检查发布文件清单、全部文档附件链接，并可附带性能数据复算。
- `scripts/prepare-clean-workspace.py`：准备全新目录，检出指定基线并应用三份当前补丁。
- `scripts/build-vdot-sew16-core.sh`：真实整核构建；`--check` 只做预检。
- `scripts/run-vdot-contract-tests.sh`：当前合同的功能与完整控制差分回归。
- `scripts/run-clean-regressions.py`：本轮候选树的接续协调器，执行 Hello/vadd、合同、完整扩展、两个烟雾及模块波形；长进程每半小时记状态。固定输出目录在最终包中已有参考记录，新一轮按手册使用手工入口与新记录路径，不直接覆盖运行。
- `scripts/review-submission.py --suite performance-data`：公开数据离线复算。

具体命令和验收标准见[干净复现手册](公开交付与干净复现操作手册.md)。依赖准备允许从本地 Git 对象读取已有上游版本，避免重复下载；不会读取原开发区的未提交源码或复制构建产物。

## 文件分类与保留范围

| 类别 | 处理 | 原因 |
| --- | --- | --- |
| 当前源码、三份补丁、脚本与协议 | 进入发布源码包 | 可从指定基线重建当前实现 |
| 设计、验收、优化报告及 PNG/SVG、图件摘录 | 进入发布源码包 | 评审可直接阅读并辨认历史与当前版本 |
| 当前正式性能原始日志、结果、分析和 CSV | 进入发布数据材料 | 保存完整输入、采样序列与统计结果 |
| 文档直接引用的其他文本证据 | 随文档进入发布材料 | 保持证据链和附件链接可用 |
| 原历史 emu、参考库、软件镜像和编译缓存 | 保留开发工作区 | 体积较大，属于开发归档和完整身份审计输入 |
| 尚存的完整历史 VCD/FST | 维持开发归档状态，不进源码包 | 已按授权清理的文件以清理台账为准，保留图件、采样和重采输入，不承诺所有旧 VCD 仍存在 |
| 私人材料、账号信息、加密提交资料 | 不进入公开源码包 | 按比赛对应渠道单独处理 |

历史文档引用的大二进制和原始波形，在发布副本中统一指向开发归档说明；原开发文档和原始附件保留。发布目录的 `manifest/public-release-files.json` 列出实际文件、用途、大小及链接调整，不把占位文件冒充原证据。
