# 核、参考库与测试入口

以下路径均相对作品目录。当前版本为 `sew16-fixed8`，支持固定八项有符号 e8/e16。

| 对象 | 路径或命令 |
| --- | --- |
| 整核 | `../XiangShan/build/sew16-fixed8/emu` |
| 参考库 | `../NEMU/build/sew16/riscv64-nemu-interpreter-so` |
| 功能源码 | `stage2/sew16/` |
| 功能运行 | `bash scripts/run-vdot-sew16.sh` |
| 当前性能源码 | `stage3/sew16-perf/` |
| INT8 应用 | `stage3/int8-gemv/` |
| 整核构建 | `bash scripts/build-vdot-sew16-core.sh` |

先按[复现手册](公开交付与干净复现操作手册.md)准备依赖及构建产物，再执行运行命令。`run-vdot-sew16.sh` 固定选择上述整组核、参考库和镜像，初始化 seed=101；四个数据种子在镜像内部执行。

## 控制验证与优化对照

当前 e16 内部取消实验使用同设计的 `../XiangShan/build/sew16-events/emu`、上述参考库及 `stage2/e16-events/`，详见[实验手册](../stage2/e16-events/e16短控制实验操作手册.md)。它记录已执行结果被取消和同代次未提交，日常功能验证仍使用推荐核。

| 对照版本 | 核目录 | 用途 |
| --- | --- | --- |
| v0.1，仅 e8 | `../XiangShan/build/emu` | oldVd 优化前的对照 |
| P1，仅 e8 | `../XiangShan/build/p1-oldvd/emu` | 删除 oldVd 假依赖后、操作数隔离前 |
| 隔离版本，仅 e8 | `../XiangShan/build/operand-isolation/emu` | 操作数隔离对照及 v4 的 e8 配对基线 |

三种旧 e8 核使用 `../NEMU/build/riscv64-nemu-interpreter-so` 和匹配的旧测试合同。旧 `run-vdot.sh`、`run-vdot-control.sh` 保留其版本默认值；当前核使用专用入口。共享功能与控制源码的 e8/e16 选择见[测试合同适配](../stage2/contract-tests/旧测试约定适配手册.md)。

## 数据复算

以下命令只读取公开包内的原始周期和统计，不启动仿真；输出使用新路径：

```bash
python3 scripts/review-submission.py --suite performance-data --out /tmp/public-performance-review.json
```

复算范围为周期、结果、协议和完整 CSV，不核验包外的仿真二进制。当前正式数据见[v4 报告](../stage3/reports/e8e16正式性能分析报告v4.md)；独立重建结果见[复现报告](../stage2/reports/公开包独立目录复现报告.md)。
