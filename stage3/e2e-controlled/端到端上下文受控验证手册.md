# E2E 上下文受控验证：小波形方案

本实验仅采集一个调用并复用已有快慢窗口。本目录是独立诊断，不修改原正式镜像、RTL、NEMU 和固定报告，不作为新的正式性能协议。

## 固定实验范围

1. 原镜像只采第 55 次调用：measured rep=3 / slot=1 / vdot，4924 周期。计时前 128、后 64 周期保护。完整程序仍运行到 GOOD TRAP，用原全样本和执行总量核对；计时边界来自已完成的原全程提交轨迹，不再定位一次。
2. 通过临时 FIFO 边写边 gzip 压缩，仅保留一个 `.vcd.gz`，不生成未压缩 VCD。分析时流式读取压缩文件。复用已完成 对应原始实验附件 的 4415 / 5178 逐周期信号及事件，旧波形不重跑，旧周期数据不复制归档。
3. 待第 1 项完整成功后运行固定 6×2 上下文矩阵，**不生成任何额外波形或全提交轨迹**。每组均有六轮、每轮 RVV/vdot 各一次，按 `impl=(round&1)^slot` 交替先后；全部 144 调用保留，没有“跑到最快为止”。

## 干预原理和局限

调用同一 `diag_wrapper`，再用固定地址的无条件跳转进入 `bench_kernel`。wrapper 位于原计时标记前；所有组的函数、调用点、跳转地址、内核、数据、校验与长度完全相同。

- phase=0..5：24 字节区域有六个固定 4 字节槽。前 phase 个槽由一个 32 位 `addi x0,x0,0` 改为两个 16 位 `c.nop`。执行 6..11 条无副作用指令，不使用变动的分支/跳转目标，尝试改变六路译码输入的指令分组历史。已完成的矩阵只测耗时、没有内部波形，不能证明真实相位保留至计时内核；phase 标签不是已经观察到的 decode 相位。
- pressure=0/1：固定六条 `addi t6,t6,1` / 六条 `mul t6,t6,t6`，t6 先初始化为 3，原内核不使用该值；同样的指令数、字节数、地址，无新访存。改变整数 ALU/乘法执行历史，而不是声称直接控制 IQ2。后续内核设置及 CSR 排空可能消除压力，无效干预也必须记录。
- 元数据一个只读参数字节仅用于校验/延后打印，不在计时路径动态选择 phase 或 pressure；真实干预是受审计的诊断 bin 字节差异。
- 原完整 `bench_kernel` 的 480 字节逐字节相等（原镜像偏移 `0x314..0x4f4`）；每个变体的内核字节再次复核。主程序布局与原正式镜像不同，前置仅四种 policy 定向检查，不是原 1000 随机预条件。即使档位变化也不能宣称复现原调用上下文或直接证明 IQ 分配因果。
- 无新波形限制下，矩阵只能证明该干预对耗时/位置效应是否有影响，不能直接观测新组的 decoder/IQ 信号，更不能据周期值反推其唯一机制。本轮唯一新内部窗口是原 4924 调用。

## 文件和操作

- `main.c`：复用原 scalar oracle、完整输出/CSR 检查，固定六轮驱动、全部结果延后打印。
- `bench.S`：只读包含原汇编内核，添加独立 caller wrapper 及固定大小的干预槽。
- `scripts/probe-e2e-other-bins.py`：名称保留，但现在**只允许一个预先固定的第 55 次调用**，自动复用历史窗口并做整次审核。没有其他档位波形队列。
- `scripts/verify-e2e-controlled.py`：固定 12 组、字节/内核保护、全部调用审核、不含 wave 参数；等待精确单调用协调日志 COMPLETE，不因锁释放就当成功。
- `stage3/tests/test-e2e-controlled.py`：压缩/FIFO/窗口、布局、元数据、缺失/乱序/退出失败、入口分组、循环分组及配对统计等 24 项合成测试。它们不是 CPU 验收。
- `stage3/tests/analyze-e2e-entry-context.py` / `analyze-e2e-loop-groups.py`：只读已有逐周期 JSON，检查入口实际分支 PC、译码组及循环尾 IQ 分配，不运行 emu。
- `stage3/tests/analyze-e2e-controlled.py`：矩阵完整结束后复核全部 144 调用、原始日志和镜像版本，按相同 round/impl/slot 比较 phase 或 pressure，不筛选最快样本。

从项目根构建（独立 build 目录，不覆盖原测量构建）：

```bash
source ../env.sh
make -C stage3/e2e-controlled ARCH=riscv64-xs
python3 stage3/tests/test-e2e-controlled.py -v
```

单调用采集和固定 12 组队列已全部完成并通过审核，**不要重复执行**。全部 144 调用及 16 配对比较保留；pressure 配对差值全为 0，phase 对 vdot 仅有 0..+1 周期变化，没有复现大档位切换。真实前缀、证据和结论见[验证报告](../reports/端到端单调用与上下文受控验证报告.md)。发生中断先核对宿主进程、协调日志、原始退出记录和数据；保留未完成尝试，不自动重复完整已通过的采集。
