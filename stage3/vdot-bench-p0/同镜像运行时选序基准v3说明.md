# 同镜像运行时选序基准 v3

当前操作入口为[v3测量手册](../docs/历史隔离核性能测量与复核手册v3.md)，包含隔离核队列、精确版本身份、复核与恢复。旧P0/v3报告仅对应旧核，不是当前隔离核结果；最新数据见[隔离核正式报告](../reports/隔离核正式性能分析报告v3.md)。

本目录通过本地包装复用 `../vdot-bench/main.c` 和 `bench.S`，独立构建smoke/full对象，避免相对源路径使两种参数误用同一对象。`runtime-config.S` 提供唯一启动参数字节；同一镜像接受first=0/1，不重新编译选序。

构建：`bash scripts/build-vdot-bench-p0.sh --smoke` 或 `--full`；运行：`bash scripts/run-vdot-bench-series.sh --runtime-order --smoke` 或正式四进程。以上从作品仓库根目录执行。串行运行、差分检查、完整日志及参数覆盖均保留，不修改RTL/NEMU。

完整合同、启动机制、探针、拒绝覆盖的重跑操作见 [P0验收与操作手册](../reports/P0完善与验收记录.md)。
