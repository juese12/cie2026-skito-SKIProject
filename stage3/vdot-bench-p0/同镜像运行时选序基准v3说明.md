# 旧 e8 同镜像运行时选序基准 v3

本目录包装共享 `../vdot-bench/main.c` 和 `bench.S`，独立构建 smoke/full 对象。`runtime-config.S` 提供启动参数；同一镜像通过 first=0/1 改变初始顺序，不重新编译选序。

从作品根目录执行 `bash scripts/build-vdot-bench-p0.sh --smoke` 或 `--full`。测量口径与计时边界见[v3 手册](../docs/历史隔离核性能测量与复核手册v3.md)；同协议结果分别见[原始核](../reports/原始核正式性能实测报告v3.md)、[P1 核](../reports/P1核正式性能实测报告.md)和[隔离核](../reports/隔离核正式性能分析报告v3.md)。当前 e8/e16 数据见[v4 报告](../reports/e8e16正式性能分析报告v4.md)。
