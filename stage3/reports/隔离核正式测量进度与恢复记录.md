## 可恢复队列

入口 `scripts/complete-vdot-isolation-performance.py` 使用benchmark-series及本阶段锁，固定源文件/工具/镜像/ELF/参考/P1日志和原报告，逐进程审计并保存检查点。完成进程的完整日志再审核并核对后跳过。中断尝试保留原文件，未取得正常退出不算正式样本；已记录失败停止诊断，不自动重试隐藏错误。若进程已完成但父队列未来得及保存，则恢复时审核pending后只接受一次。

```bash
bash scripts/vdot-step.sh isolation-performance \
  python3 -u scripts/complete-vdot-isolation-performance.py
# 中断后先查进程/锁和完整日志；使用上次打印的精确.state.json，不重新启动一整套：
bash scripts/vdot-step.sh isolation-performance-resume \
  python3 -u scripts/complete-vdot-isolation-performance.py \
  --resume stage3/logs/EXACT_QUEUE.state.json
```

每次队列使用独立ID；最终生成该ID的smoke/full清单、smoke审计、正式全样本报告JSON、P1对比JSON，以及 `stage3/reports/QUEUE-performance.md`。任何已有证据若内容不同则拒绝覆盖；旧P1报告不会被替换。检查点仅是控制状态，不作为处理器通过证据，处理器结果来自完整原始日志/差分/GOOD TRAP/真实退出审核。
